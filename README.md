# OIBSIP – Oasis Infobyte Student Internship Program

**Intern:** L V Gireesh
**Track:** Web Development & Designing
**Level completed:** Level 2 (all 4 tasks)

This repository holds my submissions for the Oasis Infobyte Web Development & Designing internship. Every project is built with plain HTML, CSS and vanilla JavaScript, with no frameworks and no build step.

## Tasks

| # | Task | Folder | What it does |
|---|------|--------|--------------|
| 1 | Calculator | [`WebDev-L2-Calculator`](./WebDev-L2-Calculator) | Browser calculator with operator chaining, delete, history and division-by-zero handling |
| 2 | Tribute Page | [`WebDev-L2-TributePage`](./WebDev-L2-TributePage) | Responsive tribute to Dr. A.P.J. Abdul Kalam with biography, timeline and quote block |
| 3 | To-Do Web App | [`WebDev-L2-ToDoApp`](./WebDev-L2-ToDoApp) | Task manager with pending and completed lists, inline editing, timestamps and localStorage |
| 4 | Login Authentication System | [`WebDev-L2-LoginAuth`](./WebDev-L2-LoginAuth) | Register, login, protected dashboard and logout with SHA-256 hashed passwords |

## How to run any project

1. Clone the repository: `git clone https://github.com/lvgireesh/OIBSIP.git`
2. Open the project folder and double-click `index.html`, or use the VS Code *Live Server* extension.
3. No installation is needed. An internet connection is only used to load Google Fonts (and the tribute page images).

## Tech used

HTML5 · CSS3 (Flexbox, Grid, custom properties) · JavaScript (ES6+) · Web Crypto API · localStorage
